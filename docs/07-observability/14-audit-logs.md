# Audit Logs

En tjeneste for å motta og lagre handlingslogger fra applikasjoner for ikke-benektbarhetsformål som *kan* inneholde personopplysninger. 

Les mer [her](https://kartverket.atlassian.net/wiki/spaces/OO/pages/2713419781/Auditlogger) og ta kontakt i [#gen-skoop](https://kartverketgroup.slack.com/archives/C05DVCJ222Y) om du tror denne tjenesten kan være relevant for ditt produkt.
