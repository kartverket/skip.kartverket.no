# Kom i gang

Under finner du video-gjennomganger av hvordan du kan sikre applikasjoner med Ztoperator på SKIP for 
identitetstilbyderne Microsoft Entra ID, ID-Porten og Ansattporten.

## 🔹  Microsoft Entra ID

Følgende eksempel går gjennom hvordan man kan konfigurere en Ztoperator-`AuthPolicy` til å beskytte en
eksempelapplikasjon og logge inn brukere mot Kartverket sin Microsoft Entra ID. Til det så benyttes Azurerator til klientregistrering, 
Skiperator til applikasjonsutrulling og Ztoperator til tilgangsstyring og innloggingsflyt.

Oppsettet for eksempelet finner du i [`env/atgcp1-sandbox/ztoperator-demo-entraid` i tilgangsstyring-apps](https://github.com/kartverket/tilgangsstyring-apps/tree/main/env/atgcp1-sandbox/ztoperator-demo-entraid).

Den beskyttede applikasjonen kan nås på [entraid-ztoperator.atgcp1-sandbox.kartverket.cloud](https://entraid-ztoperator.atgcp1-sandbox.kartverket.cloud).

### 📋 Manifester

Følgende manifester ble opprettet for å realisere eksempelet:

<details>
    <summary><strong>`AzureAdApplication`: ztoperator-demo-entraid/entraid-reg</strong></summary>

```yaml
apiVersion: nais.io/v1
kind: AzureAdApplication
metadata:
  name: entraid-reg
spec:
  claims:
    groups:
      - id: a6578085-e0ee-4168-bf97-1b3026f6f3bd # Kartverket@kartverket.no
  replyUrls:
    - url: https://entraid-ztoperator.atgcp1-sandbox.kartverket.cloud/oauth2/callback
  secretName: entraid-secret
```
</details>

<details>
    <summary><strong>`Application`: ztoperator-demo-entraid/entraid-demo-app</strong></summary>
```yaml
apiVersion: skiperator.kartverket.no/v1alpha1
kind: Application
metadata:
  name: entraid-demo-app
spec:
  podSettings:
    annotations:
      sidecar.istio.io/userVolume: |
        [
          {
            "name": "istio-oauth2",
            "secret": {
              "secretName": "authpolicy-entraid-envoy-secret"
            }
          }
        ]
      sidecar.istio.io/userVolumeMount: |
        [
          {
            "name": "istio-oauth2",
            "mountPath": "/etc/istio/config",
            "readonly": true
          }
        ]
  image: ghcr.io/kartverket/ztoperator-echo-app:v0
  port: 5000
  routingProvider: Standard
  env:
    - name: ECHO_TITLE
      value: Hello from Entra ID Ztoperator Demo
  ingresses:
    - entraid-ztoperator.atgcp1-sandbox.kartverket.cloud
```
</details>

<details>
    <summary><strong>`AuthPolicy`: ztoperator-demo-entraid/authpolicy-entraid</strong></summary>
```yaml
apiVersion: ztoperator.kartverket.no/v1alpha1
kind: AuthPolicy
metadata:
  name: authpolicy-entraid
spec:
  enabled: true
  selector:
    matchLabels:
      app: entraid-demo-app
  wellKnownURI: https://login.microsoftonline.com/7f74c8a2-43ce-46b2-b0e8-b6306cba73a3/v2.0/.well-known/openid-configuration
  allowedAudiences:
    - valueFrom:
        secretKeyRef:
          name: entraid-secret
          key: AZURE_APP_CLIENT_ID
  ignoreAuthRules:
    - paths:
        - /
        - /favicon.ico
  autoLogin:
    enabled: true
    logoutPath: /logout
    redirectPath: /oauth2/callback
    scopes:
      - api://<cluster>.<namespace>.<azure-ad-application-name>/.default
  oAuthCredentials:
    clientIDKey: AZURE_APP_CLIENT_ID
    clientSecretKey: AZURE_APP_CLIENT_SECRET
    secretRef: entraid-secret
  outputClaimToHeaders:
    - claim: preferred_username
      header: zt-mail
    - claim: name
      header: zt-name
```
</details>

Følgende manifester ble opprettet for å realisere eksempelet:

<details>
    <summary><strong>`ExternalSecret`: ztoperator-demo-idporten/idporten-secrets</strong></summary>

```yaml

  name: idporten-gsm

  provider:
    gcpsm:
      projectID: tilgangsstyring-sandbox-e5ab

  name: idporten-secrets

  secretStoreRef:
    kind: SecretStore

        key: idporten-client-id
```

## 🤖 Maskinporten

Følgende eksempel viser hvordan en API-applikasjon kan beskyttes med Maskinporten i test. I motsetning til
brukerrettede identitetstilbydere brukes det ikke innlogging eller `autoLogin`. Konsumenten henter et access-token fra
Maskinporten og sender det i `Authorization: Bearer <token>` ved kall til API-et.

Eksempelet bruker Digdirator til å opprette et Maskinporten-scope, Skiperator til applikasjonsutrulling og Ztoperator
til validering av token. Merk at Maskinporten-tokens ikke inneholder noe `aud`-claim, og at vi dermed heller ikke kan
bruke `allowedAudiences`-feltet for å validere dette. `baselineAuth` brukes her for å begrense tilgang til API-et, slik
at kun Maskinporten-tokens med riktig scope aksepteres.

### 📋 Manifester

<details>
    <summary><strong>`MaskinportenClient`: ztoperator-demo-maskinporten/maskinporten-demo</strong></summary>
```yaml
apiVersion: nais.io/v1
kind: MaskinportenClient
metadata:
  name: maskinporten-demo
spec:
  clientName: Ztoperator Maskinporten Demo
  secretName: maskinporten-demo-secret
  scopes:
    exposes:
      - enabled: true
        product: ztoperator
        name: maskinporten-demo.read
        separator: /
        consumers:
          - name: Eksempel-konsument-1
            orgno: "123456789"
          - name: Eksempel-konsument-2
            orgno: "987654321"
```
</details>

<details>
    <summary><strong>`Application`: ztoperator-demo-maskinporten/maskinporten-demo-api</strong></summary>
```yaml
apiVersion: skiperator.kartverket.no/v1alpha1
kind: Application
metadata:
  name: maskinporten-demo-api
spec:
  image: ghcr.io/kartverket/ztoperator-echo-app:v0
  port: 5000
  routingProvider: Standard
  env:
    - name: ECHO_TITLE
      value: Hello from Ztoperator Maskinporten Demo App
  ingresses:
    - maskinporten-ztoperator.atgcp1-dev.kartverket.cloud
```
</details>

<details>
    <summary><strong>`AuthPolicy`: ztoperator-demo-maskinporten/authpolicy-maskinporten</strong></summary>
```yaml
apiVersion: ztoperator.kartverket.no/v1alpha1
kind: AuthPolicy
metadata:
  name: authpolicy-maskinporten
spec:
  enabled: true
  selector:
    matchLabels:
      app: maskinporten-demo-api
  wellKnownURI: https://test.maskinporten.no/.well-known/oauth-authorization-server
  baselineAuth:
    claims:
      - claim: scope
        values:
          - kartverk:ztoperator/maskinporten-demo.read
```
</details>
